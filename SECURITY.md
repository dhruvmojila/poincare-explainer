# Security policy

The explainer is a static site: no server, no accounts, no analytics. Text typed into its query boxes is embedded in the browser and never sent anywhere. The `poincare-ball` library has one runtime dependency (`blakejs`) and performs no I/O.

If you find a vulnerability (for example in how user text is rendered on the page), email dhruvmojila098@gmail.com with details. You will get an acknowledgement within a week and a fix or mitigation plan as soon as the issue is confirmed. Please do not open a public issue for security reports.
